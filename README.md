# 🛠 Ferretería El Amigo | Business Intelligence Project

## 📌 Descripción

Este proyecto desarrolla un proceso completo de análisis de datos para una ferretería, siguiendo la metodología de un proyecto de Business Intelligence.

El objetivo es transformar datos operativos en información útil para apoyar la toma de decisiones estratégicas.

---

## 🎯 Objetivos

- Analizar el comportamiento de las ventas.
- Identificar los productos más rentables.
- Detectar clientes VIP.
- Analizar inventarios críticos.
- Construir un Dashboard Ejecutivo en Power BI.
